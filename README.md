# Win10 Mobile Network Tools

Набор BAT-инструментов для Windows 10 при подключении ПК к мобильной точке доступа Wi‑Fi.

## Состав

- `Network/Optimize_Mobile_Internet.bat` — включает ограниченный режим загрузки Delivery Optimization (без отключения Windows Update, Defender или Firewall).
- `Network/MOBILE_NET_RESTORE.bat` — возвращает значение Delivery Optimization, сохранённое скриптом оптимизации.
- `WiFi/WIFI_ALWAYS_ON.bat` — включает службу WLAN и отключает разрешение Windows выключать Wi‑Fi-адаптер для экономии энергии, если драйвер поддерживает эту настройку.
- `WiFi/WIFI_RESTORE.bat` — восстанавливает сохранённую настройку энергосбережения адаптера и исходный тип запуска WLAN AutoConfig.
- `Diagnostics/NETWORK_DIAGNOSTICS.bat` — собирает базовую диагностику сети в файл на рабочем столе.

## Перед запуском

1. Скачайте репозиторий целиком: **Code → Download ZIP**.
2. Распакуйте архив.
3. Для BAT-файлов, меняющих системные параметры, нажмите правой кнопкой → **Запуск от имени администратора**.
4. Не удаляйте каталог резервных копий: `%ProgramData%\Win10-Mobile-Network-Tools`.

Скрипты сохраняют затрагиваемые значения перед изменением. Файлы восстановления рассчитаны на запуск после соответствующего скрипта оптимизации.

## Важные ограничения

- Скрипты не отключают Microsoft Defender, Windows Firewall, DNS, TCP/IP или системные службы обновления.
- Отключение Wi‑Fi при полном переходе ПК в сон, выключении ПК или отключении точки доступа телефона скриптами не предотвращается.
- Режим лимитного подключения Windows помогает сократить часть фонового трафика, но не гарантирует, что в сеть будут выходить только выбранные приложения.
- Для точечного ограничения Chrome, Roblox и World of Tanks нужны точные пути к их EXE и отдельная настройка правил брандмауэра. Глобальная блокировка трафика намеренно не применяется.

## Безопасность

Перед изменениями создаются резервные данные в `%ProgramData%\Win10-Mobile-Network-Tools`. Если резервной копии нет, скрипт восстановления сообщит об этом и не будет угадывать исходные настройки.

Проект ориентирован на Windows 10. Поведение отдельных параметров зависит от редакции Windows, драйвера Wi‑Fi и оборудования.
