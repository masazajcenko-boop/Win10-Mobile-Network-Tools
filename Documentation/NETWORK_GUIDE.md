# Руководство: мобильный интернет

## Что делает Optimize_Mobile_Internet.bat

Скрипт сохраняет текущее значение политики Delivery Optimization `DODownloadMode`, затем устанавливает значение `0`. Это отключает одноранговую доставку обновлений с/на другие ПК. Скрипт не отключает службу Windows Update и не обещает полностью остановить фоновый трафик.

Резервная копия: `%ProgramData%\Win10-Mobile-Network-Tools\delivery-optimization-backup.txt`.

## Восстановление

Запустите `MOBILE_NET_RESTORE.bat` от имени администратора. Он восстановит сохранённое DWORD-значение либо удалит созданный скриптом параметр, если до запуска параметра не было.

## Лимитное подключение

Для Wi-Fi точки доступа телефона:
1. Откройте **Параметры → Сеть и Интернет → Wi-Fi**.
2. Выберите подключённую сеть.
3. Включите **Задать как лимитное подключение**.

Названия пунктов могут немного различаться в разных сборках Windows 10. Лимитное подключение ограничивает часть автоматических загрузок, но не является строгим фильтром приложений.

## Почему не включён режим «только Chrome/Roblox/World of Tanks»

У этих приложений могут быть дополнительные процессы, лаунчеры, службы обновления и сетевые зависимости. Глобальный запрет исходящего трафика способен нарушить работу Windows и приложений. Для точечных правил нужны точные пути к исполняемым файлам и отдельное тестирование.

## Безопасность

Не отключайте Microsoft Defender, Windows Firewall, DNS Client, DHCP Client, WLAN AutoConfig или базовые сетевые компоненты ради экономии трафика. Обновления безопасности лучше не отключать полностью.
