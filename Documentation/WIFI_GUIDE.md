# Руководство: Wi-Fi в режиме простоя

## Что делает WIFI_ALWAYS_ON.bat

Скрипт ищет физический Wi-Fi адаптер и, если драйвер поддерживает соответствующий параметр, запрещает Windows выключать адаптер для экономии энергии. До изменения сохраняется текущее значение для каждого найденного адаптера.

Резервная копия: `%ProgramData%\Win10-Mobile-Network-Tools\wifi-power-backup.txt`.

## Восстановление

Запустите `WIFI_RESTORE.bat` от имени администратора. Скрипт использует сохранённые значения. Если драйвер или адаптер изменился, восстановление может потребовать повторного подключения исходного адаптера.

## Ограничения

- Скрипт не может удерживать Wi-Fi при выключенном ПК.
- При полном переходе компьютера в сон сетевое соединение может прерываться — это зависит от оборудования и режима сна.
- Точка доступа телефона может сама отключаться по таймеру или при низком заряде.
- Если Wi-Fi продолжает пропадать, проверьте настройки сна телефона, драйвер адаптера и журнал WLAN AutoConfig.

## Диагностика

Запустите `Diagnostics/NETWORK_DIAGNOSTICS.bat`. Отчёт появится на рабочем столе. Перед публикацией отчёта удалите личные данные, включая имя сети Wi-Fi, IP-адреса и имя компьютера.
